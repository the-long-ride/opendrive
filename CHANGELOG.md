# Changelog

All notable changes to OpenDrive are documented in this file.

## [v0.3.0] - 2026-11-26

### Added

- **In-App Dual-Tab Terminal & Credential-Masked App Logs (`desktop/terminal.rs`, `runtime/{app_logs,log_mask}.rs`)**: Titlebar Terminal toggle switches the window to a two-tab diagnostics workspace featuring **Terminal Log** (`Console`, backed by credential-masked `MaskedStderrWriter` tracing output) and structured **App Logs** (`AppLogs` cards with severity, `OD-*` code badge, timestamp, target, and inline diagnostic guidance), live search and severity filtering (`All` / `WarnPlus` / `ErrorOnly`), `Copy`/`Clear`/`Back`, a 1,000-entry ring buffer, filtered stderr output (`<= WARN` or `opendrive*`), and automatic secret redaction (`GOCSPX-*`, `ya29.*`, `1//*`, `Bearer`/`BEARER` tokens, PEM private keys, Google Client ID prefixes, passwords, and query `code=` while preserving 3-digit HTTP status codes).
- **Structured `OD-*` Diagnostic Catalog & Root `llm.txt` (`opendrive-core/src/error_codes.rs`, `docs/specs/reference/error-codes.md`, `llm.txt`)**: Structured `OD-AUTH-*`, `OD-SYNC-*`, `OD-MNT-*`, `OD-STRM-*`, `OD-CFG-*`, and `OD-FONT-*` error/warning codes inferred on `WARN`/`ERROR` log events and documented alongside `llm.txt` for AI-assisted troubleshooting.
- **AI Support Prompt Modal (`desktop/modals/support.rs`)**: Titlebar Help Book button opens a copyable prompt modal pinned to the installed `v<CARGO_PKG_VERSION>` (`llm.txt` on version tag and `main`, `CHANGELOG.md`, repository root, and release URLs), instructing the AI to distinguish versions via changelog, ask the OS platform (`Windows, macOS, or Linux`), avoid inventing features, and guide step-by-step, with **Open llm.txt** and **View App Logs** (`TerminalTab::AppLogs`) shortcuts.
- **Custom UI Font Selector & Importer (`desktop/modals/font_ui.rs`, `desktop/font_actions.rs`, `runtime/{fonts,font_import,font_url}.rs`, `design/theme_fonts.rs`)**: Fixed-size searchable UI font dropdown (`Search installed fonts...` pinned above a `180px` `ScrollArea` inside `settings_ui_font_combo` with `CloseOnClickOutside` so searching neither dismisses nor shrinks the popup) in Settings with **Reset Font**, local `.ttf`/`.otf`/`.ttc` **Browse**, and Google Fonts CSS2 / public HTTPS CDN URL / local path **Import** (`20 MiB` limit, percent-encoded family queries, Regular face preference, public-HTTPS validation across initial URL, CSS `url(...)`, and redirect hops blocking private/local hosts and auth-gated `401`/`403` URLs, explicit internet-download notice, symlink skip, and Unicode Latin/CJK fallback preservation via `od_lat`/`od_cjk`).
- **Windows Console Suppression, Embedded Binary Icon & Release Page Enhancements (`build.rs`, `main.rs`, `docs/assets/opendrive.{ico,png}`, `scripts/generate-release-notes.mjs`, `.github/workflows/release.yml`)**: Windows release builds hide the popup console via `#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]` while CLI commands attach to a parent console when needed (`attach_parent_console_if_needed`), embed `opendrive.ico` directly into `opendrive.exe`, ship application icons in portable/installer packages across Windows/macOS/Linux, and render clickable asset download links and contributor avatars/handles in release notes.
- **Visual Collapsible Setup Guide (`desktop/modals/{guide,guide_visuals}.rs`)**: Collapsible Option A (Browser OAuth, expanded by default), Option B (Service Account, collapsed by default), and Troubleshooting Tips sections enhanced with 4-step vector flow diagrams.

### Changed

- **Centered Connect / Re-auth Modal & Blank Draft Reset (`desktop/drawer/{mod,sections}.rs`, `desktop/auth_reauth.rs`)**: Opening `+ Connect` from Dashboard or Explorer sidebar opens a centered modal with clean blank fields (no pre-filled saved OAuth credentials), while re-auth preserves per-account OAuth or Service Account mode and allows updating Client ID/Secret or JSON on credential rejection.
- **Settings Changelog Link, Underlined Author Link & Metadata (`Cargo.toml`, `desktop/modals/mod.rs`)**: Updated workspace author to `the-long-ride`, added a gray clickable `v<CARGO_PKG_VERSION>` link in the Settings modal header opening `CHANGELOG.md`, and made `the-long-ride` in the Settings About footer an underlined hyperlink matching text color that opens `https://the-long-ride.github.io/`.

- **Explorer `My Drive` / `Shared with me` Breadcrumb & Hierarchical Folder Sync Badges (`desktop/explorer/{mod,cache,toolbar,sidebar,file_ops_ui,list_header}.rs`, `design/icons_extra.rs`, `opendrive-sync/src/{hydrate,engine,replica_ops,sync_status}.rs`)**: Detached `Shared with me` (`parent_id: Some(0)`) from inside `My Drive` via `seed_shared_with_me_root` and migrated legacy rows, turned the Explorer root breadcrumb into a dropdown switcher (`ExplorerScope::{MyDrive, SharedWithMe}` with upload controls gated at root), added `ExplorerSyncStatus` (`Cloud`, `Indexed` via `FolderIndexed`, `PartialLocal` via half-downloaded `DownloadPartial`, `FullLocal` via `DownloadCheck`, `PendingUpload`, `Conflict`, `Syncing`) so local checkmarks only appear for fully synced items/folders, enforced a `276px..=300px` Explorer left sidebar min width (`< 236px` wrap fallback) so `Dashboard` and `+ New Account` never overlap, and moved the account status dot to the top-right corner of sidebar cards.

### Fixed

- **Automatic OAuth / Service Account Token Refresh & Poller Backoff (`opendrive-drive/src/token.rs`, `runtime/mount_manager/token_refresh.rs`, `opendrive-sync/src/poller.rs`)**: Added proactive 50-minute refresh and single-flight HTTP `401` retry/coalescing (`TokenRefresher`/`AccountTokenRefresher`) across all `DriveClient` calls instead of leaving mounted clients stuck with expired tokens (`error=auth`), and added `OD-AUTH-002` warnings with exponential backoff up to `300s` on persistent change-poll failures.
- **Windows CFAPI Partial Placeholder Conversion & Recursive Hydration (`opendrive-fs-windows/src/{cfapi_placeholders,cfapi_sys}.rs`, `opendrive-sync/src/{vfs_impl,path_time}.rs`, `runtime/explorer_ops.rs`)**: Sanitized/deduplicated Windows filenames (`sanitize_windows_entry_name`, `deduplicate_windows_names`), stripped `\\?\` prefixes in `CfSyncFilter::rel_path`, opened placeholder handles with `.write_access()` (`open_writable_placeholder`) and fixed `matches!(ph.info(), Ok(Some(_)))` detection so plain local folders convert via `ConvertOptions` instead of failing on `Ok(None)`, triggered `local_reconcile_entries` / `reconcile_account_entries` on `Bridge::explorer_list` when mounted, hydrated `NodeState::Placeholder` folders even with partial local children, and reconciled entries in BFS parent-before-child order.
- **Windows Virtual Drive Restoration under `This PC -> Devices and drives` (`opendrive-platform/src/{drive_mount,explorer_quota}.rs`, `runtime/mount_manager/{live,virtual_drive,watchdog}.rs`)**: Restored the Windows `This PC` namespace tile using `CLSID_FileSystemFolder` (`{0E5AAE11-A475-4c5b-AB00-C66DE400274E}`), `InitPropertyBag\Attributes = 0x11`, and `ShellFolder\FolderValueFlags = 0x28` with the OpenDrive logo and live Google Drive cloud quota card (`sync_this_pc_namespace`, so double-clicking opens the OpenDrive root folder directly, replacing generic `subst` drive letters while still cleaning legacy `subst` mappings via `cleanup_legacy_subst`), and isolated `explorer_quota_tests` from mutating live `HKCU` registry keys.
- Moved the Explorer sidebar account status indicator dot to the top-right corner of each account card (`desktop/explorer/sidebar.rs`), gated Explorer keyboard shortcuts when Connect (`drawer_open`) or AI Support (`support_open`) modals are open (`desktop/explorer/mod.rs`), preserved custom UI fonts across Dark/Light theme toggles (`release_actions.rs`), ensured font catalog initialization before Settings Vault actions (`settings_actions.rs`), mapped `OD-FONT-001` vs `OD-FONT-002` errors and cleared `importing` on worker disconnect (`font_actions.rs`), eliminated duplicate `set_err` log writes (`settings_actions.rs`, `auth_handlers.rs`, `release_actions.rs`), inferred `OD-*` codes before credential masking (`app_logs.rs`), consumed `Key::Escape` only for the topmost active overlay (`panels.rs`), and removed the invalid `64x64` PNG size from macOS `iconutil` icon generation (`.github/workflows/release.yml`).

## [v0.2.0] - 2026-11-26

### Added

- **Built-in Full-Viewport Drive Explorer (`desktop/explorer/*`, `desktop/explorer_actions.rs`)**: Full-viewport Bento split Cloud Explorer with per-account session persistence (breadcrumbs, search filter, sort column/direction, selection, visited-folder path cache controlled by `Settings::explorer_folder_cache`), List/Grid view toggle, multi-selection (`Ctrl/Cmd+Click`, `Shift+Click`, `Ctrl/Cmd+A`, checkboxes, click-outside clear), double-click and `Enter` to open folders/files, colored `MediaKind` vector icons (`icons_media.rs`), `Sync State` badges (`Local`/`Dirty`/`Conflict`/`Syncing`/`Cloud`), UTC timestamps, drag-and-drop uploads, and right-click context menus.
- **Lockstep Cloud + Local File Operations & Batch Actions (`opendrive-sync/src/{file_ops,file_copy}.rs`, `runtime/{explorer_file_ops,explorer_batch}.rs`, `explorer/{file_ops_ui,file_ops_modal}.rs`)**: Rename, Copy, Move, and Delete (Drive Trash + local cleanup) synchronized across Google Drive, SQLite/disk cache, and mounted placeholders, plus multi-item batch execution (`BatchOutcome`) and an internal Explorer Copy/Move clipboard (`Paste`/`Clear`).
- **Explicit Sync Down, Sync Up & Verified Clear Local (`opendrive-sync/src/replica_*.rs`, `runtime/explorer_ops.rs`)**: `sync_down_node` (atomic download + cache pinning + Windows CFAPI placeholder reconciliation), recursive `sync_up_local_path`, in-place `sync_up_node`, and two-phase Safety Invariant #3 `sync_up_and_clear_local` (verifies remote `drive_id` before removing local replicas or dehydrating CFAPI placeholders).
- **Localhost HTTP/1.1 `206` Video Streaming (`runtime/media_server.rs`, `opendrive-sync/src/{stream_cache,stream_store}.rs`)**: Token-gated `127.0.0.1` `GET`/`HEAD` `206 Partial Content` streaming server backed by a `2 MiB` chunked memory/disk `StreamCache` with concurrent head + tail (`moov`) pre-warming, single-flight coalescing, and `BandwidthLimiter`-throttled read-ahead prefetching.
- **Custom Open-With Format Rules (`opendrive-core/src/open_rules.rs`, `desktop/modals/open_rules_{ui,actions}.rs`)**: `Settings::open_with_rules` supporting extension, media-group (`@video`, `@image`, `@pdf`, `@audio`, `@code`, `@archive`), and wildcard (`*`) matching, duplicate/overlap validation, searchable Settings rule editor with native app picker, and direct localhost stream URL handoff for streaming players (`vlc`, `mpv`, `iina`, `ffplay`, etc.).
- **Driverless Windows `This PC` Namespace, Clean Quota Guards & OS Mount Exit Safety (`opendrive-platform/src/{explorer_quota,mount_cleanup}.rs`, `runtime/mount_manager/live.rs`)**: `HKCU` `This PC` Explorer namespace registration (`sync_this_pc_namespace`), clean quota guards hiding misleading storage totals when any account reports unknown/unlimited quota, and automatic CFAPI/virtual-drive/`This PC` cleanup on normal exit, `Ctrl+C`/console close, or hard kill via detached `--mount-watchdog` + `mount-owner.pid` PID-ownership guard and flushed Shell PIDL notifications (no File Explorer restart needed).
- **Smart Viewport-Aware Tooltips (`design/tooltip.rs`)**: Neo-Cel tooltips on buttons, switches, checkboxes, and status badges that automatically flip and shift inside viewport bounds.
- **Expanded Explorer, File-Op & Streaming CLI (`runtime/{cli,cli_commands,cli_self_check}.rs`)**: Added `explore`, `sync-down`, `sync-up`, `sync-clear`, `open-item [--dry-run]`, `stream [--probe]`, `rename`, `rm|delete`, `cp|copy`, `mv|move`, and an expanded `--self-check` suite (`stream=206`).

### Changed

- **Native Titlebar & Control Center UI Refinements (`desktop/titlebar.rs`, `desktop/bento.rs`, `design/icons.rs`, `design/logo.rs`)**: Unified Pause/Resume into a single toggle button in both Sync Pulse and the native titlebar (icon-only), cloned the Settings button into the native titlebar (icon-only with tooltip) beside a thin vertical divider separating app actions from window controls, upgraded `IconKind::Settings` to a 6-tooth mechanical cogwheel, added 3-accent-color (`ThemeColor`) vs monochrome (`ThemeMono`) theme-switcher vector icons, improved compact titlebar wrapping (`< 460px`), and refined Explorer/Settings layouts (left-aligned wrapped search bar, Upload dropdown left of Refresh, steady action bar width preventing double-click shifts, Open-With Rule `Cancel`/`Save` top-right).
- **95% Coverage & Zero-Exception LOC Quality Gate (`scripts/test-coverage-{rust,node}.mjs`, `scripts/loc-lint.mjs`)**: Raised both Rust (`cargo llvm-cov`) and Node (`c8`) coverage thresholds to `95%` (Lines, Functions, Regions/Branches), enforced tracked + untracked LOC limits (`<= 300` `.rs`, `<= 350` `.mjs`), and expanded unit and integration test suites across all workspace crates.

### Fixed

- **OAuth & Service Account Re-auth Flows (`desktop/auth_handlers.rs`, `runtime/auth_runner/*`, `opendrive-auth/src/loopback.rs`)**: Preserved account folder names while updating nickname/read-only state, prevented leaking OAuth credentials into Service Account re-auth flows, fixed pending browser-auth `Sign In`/`Copy Link` routing, and eliminated nested Tokio `block_on` during async avatar caching.
- **Drive Hydration, Shared Items & Cache Reconciliation (`opendrive-sync/src/{hydrate,poller}.rs`, `opendrive-drive`)**: Resolved canonical real root IDs, surfaced unparented top-level files and `Shared with me` shortcuts, pruned remotely deleted clean children, and invalidated stale disk/stream cache entries on MD5/revision changes.
- **Windows Multi-Account CFAPI & Mount Isolation (`opendrive-fs-windows/src/{lib,provider,cfapi_sys}.rs`, `runtime/mount_manager/*`)**: Isolated per-account CFAPI root nodes (`connect_live_at`, `ProviderBridge::with_root`), sanitized sync root IDs, and guarded legacy `subst` cleanup so unrelated user drives are never unmounted.

## [v0.1.0] - 2026-11-19

### Added

- **Pure-Rust Desktop Control Center (`opendrive-app`)**: `eframe` / `egui` (`glow`) desktop UI in Dark & Light Neo-Brutalist Bento style with frameless 8-edge resizing, custom non-selectable draggable titlebar, `Ctrl/Cmd` keyboard & scroll-wheel zoom, bottom-right auto-dismissing toasts (5s), Settings modal, and step-by-step Google Cloud Console Setup Guide modal.
- **Multi-Account Authentication & Secure Storage**: Browser OAuth 2.0 PKCE loopback (**Sign in with Google** & **Copy Link**), in-place **Re-auth**, **Service Account JSON (No Login)** RS256 JWT exchange, OS keyring secret persistence (`OsKeyringStore`), editable account aliases, cached rounded avatars, and AES-GCM + Argon2id `.odcred` encrypted credential backup export/import.
- **Cross-Platform Virtual Filesystems & Sync Engine**: `SyncEngine` with SQLite metadata store, upload queue, cache eviction, conflict handling, lazy subfolder hydration, shared-folder shortcut materialization, Windows Cloud Files (`cloud-filter` CFAPI) + optional virtual drive letter (`O:\`), macOS localhost NFSv3 (`nfsserve`), Linux FUSE3, and System Tray integration with live usage summary.
- **CLI & Quality Gates**: `authorize`, `list-root`, `status`, `mount`, `--self-check`, and full Rust + Node CI/release automation (`windows` portable + NSIS installer, `linux` tarball + `.deb` + `.AppImage`, `macos` portable + `.dmg` installer).
