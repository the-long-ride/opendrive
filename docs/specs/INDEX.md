# OpenDrive Specification Index

OpenDrive is a multi-account Google Drive desktop client in Rust (`crates/opendrive-*`) with a pure-Rust `eframe` / `egui` native Control Center UI (`crates/opendrive-app/`) and Node.js quality-gate tooling (`scripts/`).

## Architecture

- [Workspace core domain, settings, and platform integration](architecture/workspace-overview.md) — Search here for `Account`, `CredentialSet`, `Settings` (`virtual_drive_enabled`, `virtual_drive_letter`), `AppController`, config JSON persistence, OS dirs, single-instance lock, `drive_mount` (`subst` + Explorer `DriveIcons`), and tray menu model under `crates/opendrive-core/` and `crates/opendrive-platform/` (`architecture`, `core`, `accounts`, `settings`, `controller`, `platform`, `tray`, `virtual-drive`).
- [SQLite metadata store, cache index, and upload queue](architecture/sqlite-store-and-cache.md) — Search here for `Store`, SQLite schema migrations, `nodes` hierarchy, `change_tokens`, `cache_files`, eviction candidate queries, and `upload_queue` durability under `crates/opendrive-store/` (`sqlite`, `store`, `cache`, `upload-queue`, `eviction`).
- [OS Filesystem Adapters (Linux FUSE3, macOS NFSv3, Windows CFAPI)](architecture/os-filesystem-adapters.md) — Search here for `FuseFrontend`, `NfsFrontend`/`NfsBackend` (`nfsserve`), and `CloudFilesFrontend` (`register_sync_root_at`, `connect_live_at`)/`ProviderBridge` (`with_root`, `root_node`)/`CfSyncFilter` (`cloud-filter`) under `crates/opendrive-fs-linux/`, `crates/opendrive-fs-macos/`, and `crates/opendrive-fs-windows/` (`vfs`, `fuse3`, `nfs3`, `cfapi`, `linux`, `macos`, `windows`).
- [Quality Gate, Desktop Launcher, and CI Scripts](architecture/quality-gate-and-ci.md) — Search here for `desktop-launch.mjs`, `launch-desktop.mjs`, `source-policy.mjs`, `loc-lint.mjs`, `lint.mjs`, `ci-changes.mjs`, and 90% Node/Rust coverage runners under `scripts/` (`ci`, `quality-gate`, `lint`, `loc`, `coverage`, `desktop-launch`).
