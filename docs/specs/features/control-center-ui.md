# Native Control Center Desktop UI

## Purpose and boundaries
Implements the lightweight, pure-Rust desktop Control Center inside `crates/opendrive-app/` using `eframe` / `egui` (`glow` backend) with zero WebView or HTTP daemon dependencies.

- **In scope**: `ControlCenterApp` state/mutation dispatcher and centered `940px` Bento layout (`desktop.rs`, `desktop/auth_handlers.rs`, `desktop/settings_actions.rs`, `desktop_panels.rs`), custom frameless draggable titlebar (`desktop_titlebar.rs`), Bento Grid hero telemetry/storage overview with dotted backdrop (`desktop_bento.rs`), centered Settings modal (`desktop_modal.rs`), Connected Accounts card (`desktop_ledger.rs`) with cached Google profile avatars (`avatars.rs`) & inline Connect Account drawer supporting Browser OAuth + Service Account JSON (`desktop_drawer.rs`, `desktop_drawer/sections.rs`), dual `ColorPop`/`DarkStudio` `ThemePalette` (`theme.rs`), shared stacked-drive portal logo (`logo.rs`), 22 geometric `1.5px` stroke vector icons (`icons.rs`), pill/card/avatar/progress primitives (`widgets.rs`, `widgets_controls.rs`), formatters/step helpers/validation (`formatters.rs`), frameless native window bootstrap + System Tray bridge (`desktop_window.rs`, `desktop_tray.rs`), and unit/headless GUI/end-to-end tests (`desktop_ui_tests.rs`, `desktop_render_tests.rs`, `bento_avatar_tray_tests.rs`, `formatters_tests.rs`, `auth_flow_tests.rs`, `reauth_flow_tests.rs`, `common_auth_helpers.rs`).
- **Out of scope**: Synchronous controller/sync persistence (`Bridge` in `bridge.rs`), background auth workers (`auth_runner.rs`), CLI entrypoints (`main.rs`), and VFS sync algorithms (`opendrive-sync`).

## Observable behavior
- **Dark Neo-Brutalism (`DarkStudio` default) & Light (`ColorPop`) Theme (`theme.rs`, `desktop.rs`, `desktop_bento.rs`)**: Defaults to `ThemeMode::DarkStudio` (`#111217` canvas with `#252834` `24px` dot matrix, `#181A20` primary cards, `#1E2029` subcards, `#232631` neutral pills, `#FF5E93` Pink, `#22D3EE` Cyan, `#7C74FF` Indigo accents, `#090A0F` ink strokes) with runtime `ToggleTheme` switching to harmonized Light `ThemeMode::ColorPop`. `apply_studio_theme` sets `visuals.selection.stroke = Stroke::new(1.5, Color32::WHITE)` so selected text never blends into selection highlight background.
- **Tactile Primitives, Image-3 Shadows, Animated Status Badges & Pastel Usage Bars (`widgets.rs`, `widgets_controls.rs`, `icons.rs`)**: `bento_card_with_header` / `bento_card` (`12px` radius) renders Image-3 dual `(-2.5, -2.5)` Pink / `(+2.5, +2.5)` Cyan `0px`-blur hard offset shadows with `1.5px` dark separation stroke. `pill_button` (`8px` radius) renders `(+2.0, +2.0)` hard offset shadows and hover/press displacement across all enabled variants (`Primary`, `Default`, `TactilePill`, `Danger`, `Toggle`). `status_pill` (`7px` radius) uses `tone_badge_style` `(bg, fg, border)` with a `1.5px` stroke and animates a pulsing halo around the dot on `StatusTone::Connected`. `thin_usage_bar` & `usage_bar_color` color both account bars and the `Storage & Workspace` total `quota_progress_bar` pastel green (`< 75%`), pastel orange (`75%..<90%`), or pastel red (`>= 90%`). `paint_icon` draws 23 geometric `1.5px` stroke icons (including `Edit`).
- **Frameless Resizable Window, Keyboard Zoom & Minimal Native Titlebar (`desktop_window.rs`, `desktop_resize.rs`, `desktop_titlebar.rs`, `desktop_panels.rs`)**: Window enables `.with_resizable(true)` at `[960, 720]` default / `[610, 480]` min, handles 8-direction `6px` perimeter resizing (`handle_frameless_resize`), and supports `Ctrl/Cmd + =`, `Ctrl/Cmd + -`, `Ctrl/Cmd + 0`, and `Ctrl/Cmd + mouse scroll` zoom (`0.7..=2.0` via `handle_keyboard_zoom`). `render_custom_titlebar` keeps ONLY the OpenDrive portal logo + non-selectable `"OpenDrive"` label (`Label::selectable(false)`), `Pause` / `Resume` sync buttons, `Color`/`Dark` theme toggle, and `Minimize` / `Maximize` / `Close` window chrome, returning `top_bar_bottom` and wrapping cleanly below `560px` with empty-space-only window drag. `render_notice_toast` renders floating bottom-right status/error toasts (`Order::Foreground`) that auto-dismiss after 5 seconds (`TOAST_TIMEOUT` / `tick_notice_timeout`).
- **Centered Bento Grid Overview (`desktop_bento.rs`, `desktop_panels.rs`)**: `Storage & Workspace` keeps `O:\ Active` badge + `total.detail_text` + threshold-colored `quota_progress_bar` + `Open Folder` + `Open Settings`; `Sync Pulse` displays the global sync health badge alongside the Docs badge + `Cache` readout and 3 telemetry subcards (`10px` radius).
- **Scrollable Settings Modal, Optional Release Check & Encrypted Backup (`desktop/modals/settings.rs`, `desktop/modals/release.rs`, `runtime/release_check.rs`)**: Positions the `Order::Middle` backdrop strictly below `top_bar_bottom` with generous top/bottom margins so the native titlebar remains visible and usable, hides the `ScrollArea` scrollbar (`ScrollBarVisibility::AlwaysHidden`) while preserving scrolling, omits right-side switch status labels, includes an optional **Check for GitHub Releases** switch (`check_updates`, off by default) with a right-side **Check Now** refresh button (showing `render_release_modal` with **Open Release Page**, **Never Show This Version**, and **Later**), places **Bandwidth** & **Cache Limit** sliders side-by-side in 2 columns (`>= 420px`), and includes the stacked **Encrypted Credential Backup (`.odcred`)** UI.
- **Connected Accounts Header, Card Relayout, Switch Label, Alias Editing & Setup Guide Modal (`desktop_ledger.rs`, `desktop_ledger/row.rs`, `desktop_drawer.rs`, `desktop_guide_modal.rs`)**: Header displays plain `"N account(s)"` text + `+ Connect` / `Close` button without a subtitle. Account cards (`10px` radius) align each account's sync status badge to the right-most edge, place `"Sync On"` / `"Paused"` beside `tactile_switch`, keep mount path + clickable `Open` folder button (`OpenAccountFolder`) + storage readout on the controls row when wide (`>= 760px`) and move it directly above `thin_usage_bar` when narrow, and support inline `Alias:` editing (`Edit` button). Connect Drawer includes **Import Backup** and **Setup Guide** (`render_cloud_guide_modal`), which renders below `top_bar_bottom` with list-style highlighted Google Cloud Console instructions for OAuth 2.0 Desktop App, Service Account JSON, Quick Troubleshooting (including missing scope `403` resolution), and **Open Google Cloud Console**.
- **Account Avatars, Logo & Integrated System Tray (`avatars.rs`, `logo.rs`, `desktop_tray.rs`, `desktop.rs`)**: `decode_avatar_color_image` scales cached avatars with `object-fit: contain` onto a transparent `72x72` canvas and `account_avatar` clips them cleanly inside `7px`/`9px` rounded corners (`RectShape::with_texture`) with monogram fallback; `logo.rs` shares the portal mark across bar/window/tray; `DesktopTray` prepends a disabled read-only `TrayAction::Summary` item updated live via `sync_tray_summary` (`Close` hides to tray when `tray_active`, `Show OpenDrive` restores, `Quit` exits).
