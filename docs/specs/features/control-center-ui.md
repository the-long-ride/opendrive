# Native Control Center Desktop UI

## Purpose and boundaries
Implements the lightweight, pure-Rust desktop Control Center inside `crates/opendrive-app/` using `eframe` / `egui` (`glow` backend) with zero WebView or HTTP daemon dependencies.

- **In scope**: `ControlCenterApp` state/mutation dispatcher (`desktop/mod.rs`, `desktop/actions.rs`, `desktop/auth_handlers.rs`, `desktop/settings_actions.rs`, `desktop/panels.rs`), custom frameless draggable titlebar (`desktop/titlebar.rs`), Bento Grid overview (`desktop/bento.rs`), full-viewport Drive Explorer (`desktop/explorer/{mod,cache,sidebar,toolbar,toolbar_actions,items,items_grid,file_ops_ui,file_ops_modal,selection,list_header,jobs}.rs`, `desktop/explorer_actions.rs`), Settings modal with **Open With Rules** (`desktop/modals/settings.rs`, `desktop/modals/open_rules_ui.rs`, `desktop/modals/release.rs`), Setup Guide modal (`desktop/modals/guide.rs`, `desktop/modals/guide_content.rs`), Connected Accounts card (`desktop/ledger/{mod,row}.rs`) with cached Google profile avatars (`design/avatars.rs`) & inline Connect Account drawer (`desktop/drawer/{mod,sections}.rs`), dual `ColorPop`/`DarkStudio` `ThemePalette` (`design/theme.rs`), shared stacked-drive portal logo (`design/logo.rs`), 47 geometric vector icons (`design/icons.rs`, `design/icons_media.rs`, including 6-tooth cogwheel `Settings` and `ThemeColor`/`ThemeMono`), pill/badge/card/avatar/progress primitives (`design/widgets.rs`, `design/widgets_badges.rs`, `design/widgets_controls.rs`), formatters/validation (`design/formatters.rs`), frameless native window + System Tray bridge (`shell/{window,tray}.rs`), and unit/headless GUI/end-to-end tests (`tests/*`).
- **Out of scope**: Synchronous controller/sync persistence (`Bridge`), Explorer/Media runtime & CLI (`runtime/explorer_ops.rs`, `runtime/media_server.rs`, `runtime/cli*.rs`), background auth workers (`runtime/auth_runner`), and VFS sync algorithms (`opendrive-sync`).

## Observable behavior
- **Dark Neo-Brutalism (`DarkStudio` default) & Light (`ColorPop`) Theme (`design/theme.rs`, `desktop/mod.rs`, `desktop/bento.rs`)**: Defaults to `ThemeMode::DarkStudio` (`#111217` canvas with `#252834` `24px` dot matrix, `#181A20` primary cards, `#1E2029` subcards, `#232631` neutral pills, `#FF5E93` Pink, `#22D3EE` Cyan, `#7C74FF` Indigo accents, `#090A0F` ink strokes, and `cloud_fg` / `cloud_tint` / `cloud_border` sky-blue Cloud/Syncing tokens) with runtime `ToggleTheme` switching to harmonized Light `ThemeMode::ColorPop`. `apply_studio_theme` sets `visuals.selection.stroke = Stroke::new(1.5, Color32::WHITE)` so selected text never blends into selection highlight background, and installs OS Unicode/CJK fallback fonts (`install_unicode_fallback_fonts`) for Proportional and Monospace text.
- **Tactile Primitives, Media Icons, Smart Tooltips & Quota Guards (`design/tooltip.rs`, `design/widgets.rs`, `design/widgets_controls.rs`, `design/icons.rs`, `design/icons_media.rs`, `design/avatars.rs`, `design/formatters.rs`)**: `bento_card_with_header` / `bento_card` (`12px` radius) renders dual `(-2.5, -2.5)` Pink / `(+2.5, +2.5)` Cyan `0px`-blur hard offset shadows with `1.5px` dark separation stroke. `pill_button` and `pill_button_tip` (`8px` radius) render `(+2.0, +2.0)` hard offset shadows and hover/press displacement across all enabled variants; `status_pill` and `icon_status_pill` render compact `28x24` icon-only vector badges (`7px` radius, `1.5px` stroke, subtle pulse halo on `StatusTone::Connected`, and `pal.cloud_*` tokens for `Placeholder` / `Hydrating`) across Dashboard headers (`Monitor` for This PC / platform workspace, `Link` / `DocSheet` for Docs mode, `Refresh`/`Pause`/`Alert`/`Cloud` for Sync Pulse), Connected Accounts rows (`Check`/`Pause`/`Key`/`Alert`), and Explorer entries (`Cloud`, `DownloadCheck`, `CloudUpload`, `Alert`, `Refresh`). Every `pill_button` (titlebar, Bento, ledger, drawer, modals, toasts, Explorer sidebar/toolbar, and context-menu items), `status_pill` / `icon_status_pill` status badge, `tactile_switch` / `tactile_switch_tip` / `setting_switch_row` switch, and the alias-rename checkbox renders a smart Neo-Cel tooltip on `Order::Tooltip` (`compute_smart_tooltip_rect` defaults below target, flips above when bottom clipping would occur, and shifts horizontally so 100% of tooltip + `2px` shadow stays inside the viewport). `paint_icon` draws `Monitor` / `Link` directly and delegates media/explorer icons (`Cloud`, `DownloadCheck`, `MoveRight`, `Explore`, `ArrowLeft`, `ChevronRight`, `Search`, `Grid`, `List`, `CloudDownload`, `CloudUpload`, `CloudClear`, `Image`, `Video`, `Pdf`, `Audio`, `FileText`, `DocSheet`) to `icons_media.rs`. `summarize_total_storage` (`has_exact_total`) and `format_account_storage` / `ledger/row.rs` require `quota > 0 && quota >= used`, falling back to `"{u} used"` / `"{u} across {account_count} {unit}"` and hiding progress bars otherwise. `format_modified_date` renders UTC `"YYYY-MM-DD HH:MM"` or `"—"`.
- **Full-Viewport Drive Explorer (`desktop/explorer/{mod,cache,list_header,selection,sidebar,toolbar,items,items_grid,file_ops_ui,file_ops_modal,jobs}.rs`, `desktop/explorer_actions.rs`, `desktop/ledger/row.rs`)**: Each account card includes a primary **Explore** button (`UiAction::OpenExplorer(id)`) in its top-right header next to the icon-only status badge, switching `render_root` to the full-viewport Bento split Explorer (`ExplorerState` with per-account `AccountExplorerSession` persistence including `folder_cache: HashMap<NodeId, Vec<ExplorerEntry>>` + `cache_epoch`, `anchor_id` + `selected_id` + visible-filtered `selected_ids` passed as `SelectionRef`, `ExplorerSortColumn` + `sort_desc`, `ExplorerClipboard` batch copy/move without mutating OS text clipboard, and `ExplorerModal` across account switches). When `Settings::explorer_folder_cache` is enabled (default), navigating back and forth across previously visited folders serves cached entries from `folder_cache` immediately without network calls until a user mutation (`Mutated` / `BatchFinished` forcing remote refresh), `Purge Unpinned Cache`, `SetDocsMode`, `ImportVault`, folder-renaming `SaveAlias`, or manual `Refresh` invalidates the cache (while `Opened` updates local entries via `sync_local_folder_entries`); disabling the setting clears `folder_cache` and forces fresh fetches on every folder navigation. Wide viewports render the left account sidebar (`pop_pink` `+3.5px` shadow, top header row with left **Dashboard** button and top-right **+ New Account** button, and compact quota cards) and right browser card (`pop_cyan` `+3.5px` shadow) as equal-height `12px` Neo-Pop Bento cards (`1.5px` `tactile_ink` border) over `paint_bento_dots`. The main pane renders full-width breadcrumbs on Row 1 and places its action bar alongside `[Search folder... | List | Grid | Upload | Refresh]` on Row 2 in wide viewports (reserving steady width via `stable_action_controls_width` so selecting an item never wraps the toolbar mid-double-click)—or wraps the left-aligned search/view/upload/refresh row above and selection action bar directly below when horizontal space is narrower—featuring a conditional `"{N} selected"` clear pill (`"Clear current selection"` tooltip, hidden at `0` selected), single-selection `Open` (`Primary`, navigating into selected folders or opening files like stationary double-click, context-menu `Open`, and `Enter`), a compact **Sync** dropdown (`Sync Down`, `Sync Up`, `Sync Up & Clear Local`; disabled when `0` selected), always-visible `Copy`/`Move`/`Delete` pills (disabled when nothing mutable is selected), contextual `Rename`/`Copy Stream URL` pills, and active clipboard `Paste`/`Clear`, with the merged **Upload** dropdown (`Upload Files`, `Upload Folder`) positioned directly to the left of `Refresh` alongside sortable List headers (`Name`, `Sync State`, `Modified`, `Size` with vector `ChevronUp`/`ChevronDown`), theme-styled header/row checkboxes (`Unchecked`, `Indeterminate`, `Checked`), click-outside unselection across empty List/Grid space, unclipped Grid cards showing both modified date and size, and compact `menu_pill_button` context menus (`ui.set_max_width(menu_w)`).
- **Frameless Resizable Window, Keyboard Zoom & Minimal Native Titlebar (`shell/window.rs`, `desktop/resize.rs`, `desktop/titlebar.rs`, `desktop/panels.rs`)**: Window enables `.with_resizable(true)` at `[960, 720]` default / `[610, 480]` min, handles 8-direction `6px` perimeter resizing (`handle_frameless_resize`), and supports `Ctrl/Cmd + =`, `Ctrl/Cmd + -`, `Ctrl/Cmd + 0`, and `Ctrl/Cmd + mouse scroll` zoom (`0.7..=2.0` via `handle_keyboard_zoom`). `render_custom_titlebar` keeps the OpenDrive portal logo + non-selectable `"OpenDrive"` label, `Color`/`Dark` theme toggle (`ThemeColor` 3-color vector dots on `"Color"` and `ThemeMono` monochrome dots on `"Dark"`), icon-only `Sync` pause/resume toggle button (`IconKind::Pause` / `IconKind::Play`) to its right, icon-only `Settings` cogwheel clone (`IconKind::Settings` with `"Open application preferences and sync settings"` tooltip, dispatching `UiAction::ToggleSettings(None)`) to the right of `Sync`, a thin `1.5x18` vertical `card_border` divider (`vertical_divider`), and `Minimize`/`Maximize`/`Close` window chrome (wrapping `[Theme] [Sync] [Settings]` below `< 460px`). `render_notice_toast` renders floating bottom-right status/error toasts (`Order::Foreground`) that auto-dismiss after 5 seconds.
- **Centered Bento Grid Overview (`desktop/bento.rs`, `desktop/panels.rs`)**: `Storage & Workspace` displays `This PC Active` badge + `total.detail_text` + guarded `quota_progress_bar` (when `total.has_exact_total`) + `Open Folder` + `Open Settings` + **Explore** (which dispatches `UiAction::OpenExplorer("")` to open the first account in list order or Explorer empty state); `Sync Pulse` displays the global sync health badge alongside the Docs badge + `Cache` readout and 3 telemetry subcards. Root `render_notice_toast` renders floating bottom-right status/error toasts with `(+3.5, +3.5)` Neo-Pop offset shadows (`ColorPop` uses soft periwinkle `#D6D4F0`/`#B6B3DC` canvas tokens).
- **Scrollable Settings Modal, Open-With Format Rules, Release Check & Encrypted Backup (`desktop/modals/{settings,open_rules_ui,open_rules_actions,release}.rs`, `runtime/release_check.rs`)**: Renders dimmed backdrop at `Order::Middle` and modal card at `Order::Foreground` at `768px` max width (`1.2x` of prior `640px`) below `top_bar_bottom` with hidden scrollbar, Escape-key close, `Show OpenDrive in This PC` toggle, `Cache Explorer Folder Paths` toggle (`UiAction::ToggleExplorerFolderCache`, default ON), optional **Check for GitHub Releases**, side-by-side **Bandwidth** & **Cache Limit** sliders, **Open With Rules (Custom Format Apps)** (top Search + `+ Add` row with `pill_button_tip` tooltips, collapsible 3-control aligned editor card with top-right `Cancel`/`Save` header buttons and `Extension / Group`, `Application`, `Browse` (`Save` validation blocking invalid, `*`-overlapping, or duplicate extensions across apps), live-filtered `Edit`/`Remove` cards, and `RemoveOpenWithRule` calling `Bridge::remove_open_with_rule` so legacy duplicates never block deletion), and **Encrypted Credential Backup (`.odcred`)** UI. `ControlCenterApp::on_exit` and `WindowForceQuit` share `shutdown_session()` to shut down mounts on exit.
- **Connected Accounts Header, Card Relayout, Re-auth Error & Pending Routing (`desktop/ledger/{mod,row}.rs`, `desktop/drawer/{mod,sections}.rs`, `desktop/auth_handlers.rs`, `desktop/modals/{guide,guide_content}.rs`)**: Header displays plain `"N account(s)"` text + `+ Connect` / `Close` button. Account cards render a wrapped `left_to_right` action bar (`Sign In` and, for OAuth accounts, `Copy Link`) routing pending rows to `OpenAuthBrowser`/`CopyAuthLink` without canceling the active session; Service Account (`credential_set_id.is_nil()`) re-auth routes to stored Service Account auth or the Service Account drawer without leaking saved OAuth credentials; inline OAuth (`is_credential_rejection_error`) and Service Account re-auth failures surface error toasts (`set_err`) and auto-open the prefilled drawer.
- **Account Avatars, Logo & Integrated System Tray (`design/avatars.rs`, `design/logo.rs`, `shell/tray.rs`, `desktop/mod.rs`)**: `decode_avatar_color_image` scales cached avatars onto `72x72`; `logo.rs` shares the portal mark across bar/window/tray/Windows `opendrive.ico`; `DesktopTray` prepends a disabled read-only `TrayAction::Summary` item updated live via `sync_tray_summary`.
