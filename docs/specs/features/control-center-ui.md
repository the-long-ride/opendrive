# Native Control Center Desktop UI

## Purpose and boundaries
Implements the lightweight, pure-Rust desktop Control Center inside `crates/opendrive-app/` using `eframe` / `egui` (`glow` backend) with zero WebView or HTTP daemon dependencies.

- **In scope**: `ControlCenterApp` state/mutation dispatcher (`desktop/{mod,actions,dispatch,auth_handlers,auth_reauth,settings_actions,font_actions,release_actions,panels}.rs`), custom frameless draggable titlebar (`desktop/titlebar.rs`), dual-tab Terminal & App Logs workspace (`desktop/terminal.rs`), Bento Grid overview (`desktop/bento.rs`), full-viewport Drive Explorer (`desktop/explorer/{mod,cache,sidebar,toolbar,toolbar_actions,items,items_grid,file_ops_ui,file_ops_modal,selection,list_header,jobs}.rs`, `desktop/explorer_actions.rs`), Settings modal with **Open With Rules**, **UI Font** selector/importer & version link (`desktop/modals/{settings,mod,font_ui,open_rules_ui,release}.rs`), Setup Guide & AI Support Prompt modals (`desktop/modals/{guide,guide_content,guide_visuals,support}.rs`), Connected Accounts card (`desktop/ledger/{mod,row}.rs`) with cached Google profile avatars (`design/avatars.rs`) & centered Connect/Re-auth modal (`desktop/drawer/{mod,sections}.rs`), dual `ColorPop`/`DarkStudio` `ThemePalette` + dynamic UI font loader (`design/{theme,theme_fonts}.rs`), shared stacked-drive portal logo (`design/logo.rs`), geometric vector icons (`design/{icons,icons_extra,icons_media}.rs`), pill/badge/card/avatar/progress primitives (`design/widgets*.rs`), formatters/validation (`design/formatters.rs`), frameless native window + System Tray bridge (`shell/{window,tray}.rs`), and unit/headless GUI/end-to-end tests (`tests/*`).
- **Out of scope**: Synchronous controller/sync persistence (`Bridge`), runtime logging/font discovery (`runtime/{app_logs,log_mask,fonts,font_import}.rs`), Explorer/Media runtime & CLI (`runtime/explorer_ops.rs`, `runtime/media_server.rs`, `runtime/cli*.rs`), background auth workers (`runtime/auth_runner`), and VFS sync algorithms (`opendrive-sync`).

## Observable behavior
- **Dark Neo-Brutalism (`DarkStudio` default), `ColorPop` Light Theme & Custom UI Font Loader (`design/theme.rs`, `design/theme_fonts.rs`, `desktop/mod.rs`, `desktop/font_actions.rs`, `desktop/bento.rs`)**: Defaults to `ThemeMode::DarkStudio` (`#111217` canvas with `#252834` `24px` dot matrix, `#181A20` primary cards, `#1E2029` subcards, `#232631` neutral pills, `#FF5E93` Pink, `#22D3EE` Cyan, `#7C74FF` Indigo accents, `#090A0F` ink strokes, and `cloud_fg` / `cloud_tint` / `cloud_border` sky-blue Cloud/Syncing tokens) with runtime `ToggleTheme` switching to harmonized Light `ThemeMode::ColorPop` (and resetting `applied_font` so custom UI fonts stay active across theme toggles). `apply_studio_theme` sets `visuals.selection.stroke = Stroke::new(1.5, Color32::WHITE)` so selected text never blends into selection highlight background, while `apply_ui_font` prepends user-selected/imported custom `.ttf`/`.otf`/`.ttc` font bytes into `FontFamily::Proportional` while retaining OS Latin/CJK fallback fonts (`od_lat`, `od_cjk`) for Proportional and Monospace text.
- **Tactile Primitives, Extra Chrome Icons, Media Icons, Smart Tooltips & Quota Guards (`design/{tooltip,widgets,widgets_controls,icons,icons_extra,icons_media,avatars,formatters}.rs`)**: `bento_card_with_header` / `bento_card` (`12px` radius) renders dual `(-2.5, -2.5)` Pink / `(+2.5, +2.5)` Cyan `0px`-blur hard offset shadows with `1.5px` dark separation stroke. `pill_button` and `pill_button_tip` (`8px` radius) render `(+2.0, +2.0)` hard offset shadows and hover/press displacement across all enabled variants; `status_pill` and `icon_status_pill` render compact `28x24` icon-only vector badges (`7px` radius, `1.5px` stroke, subtle pulse halo on `StatusTone::Connected`, and `pal.cloud_*` tokens for `Placeholder` / `Hydrating`) across Dashboard headers (`Monitor` for This PC / platform workspace, `Link` / `DocSheet` for Docs mode, `Refresh`/`Pause`/`Alert`/`Cloud` for Sync Pulse), Connected Accounts rows (`Check`/`Pause`/`Key`/`Alert`), and `Explorer` (`Cloud` via `Cloud`, `Indexed` via `FolderIndexed`, `PartialLocal` via half-downloaded `DownloadPartial`, `FullLocal` via `DownloadCheck`, `PendingUpload` via `CloudUpload`, `Conflict` via `Alert`, `Syncing` via `Refresh`). Every `pill_button`, `status_pill` / `icon_status_pill`, `tactile_switch` / `tactile_switch_tip` / `setting_switch_row`, and alias-rename checkbox renders a smart Neo-Cel tooltip on `Order::Tooltip` (`compute_smart_tooltip_rect` flips/shifts cleanly inside the viewport). `paint_icon` delegates chrome icons (`Settings`, `Monitor`, `Link`, `Terminal`, `HelpBook`) to `icons_extra.rs` and media/explorer icons to `icons_media.rs`. `summarize_total_storage` (`has_exact_total`) and `format_account_storage` / `ledger/row.rs` require `quota > 0 && quota >= used`, falling back to `"{u} used"` / `"{u} across {account_count} {unit}"` and hiding progress bars otherwise. `format_modified_date` renders UTC `"YYYY-MM-DD HH:MM"` or `"—"`.
- **Full-Viewport Drive Explorer (`desktop/explorer/{mod,cache,list_header,selection,sidebar,toolbar,items,items_grid,file_ops_ui,file_ops_modal,jobs}.rs`, `desktop/explorer_actions.rs`, `desktop/ledger/row.rs`)**: Each account card includes a primary **Explore** button (`UiAction::OpenExplorer(id)`) in its top-right header next to the icon-only status badge, switching `render_root` to the full-viewport Bento split Explorer (`ExplorerState` with per-account `AccountExplorerSession` persistence including `ExplorerScope::{MyDrive, SharedWithMe}`, `folder_cache: HashMap<NodeId, Vec<ExplorerEntry>>` + `cache_epoch`, `anchor_id` + `selected_id` + visible-filtered `selected_ids`, `ExplorerSortColumn` + `sort_desc`, `ExplorerClipboard`, and `ExplorerModal`). Row 1 renders the root breadcrumb via `menu_dropdown_button` (`My Drive` / `Shared with me` switcher dispatching `UiAction::ExplorerSwitchScope`, keeping `Shared with me` outside `My Drive` and disabling `Upload` at the virtual `Shared with me` root), while Row 2 aligns the action bar with `[Search folder... | List | Grid | Upload | Refresh]` (`stable_action_controls_width`) or wraps cleanly when narrower. When `Settings::explorer_folder_cache` is enabled (default), navigating back and forth serves cached entries from `folder_cache` immediately until user mutation, purge, Docs mode change, vault import, folder rename, scope switch, or manual `Refresh`. Wide viewports (`avail.x >= 720.0`) enforce a `276.0..=300.0` sidebar card min width (with a `< 236.0` inner width `horizontal_wrapped` fallback in `sidebar.rs` so `Dashboard` and `+ New Account` never overlap; account cards place the `7x7` status dot at the top-right corner) and right browser card over `paint_bento_dots`, while `overlay_open` gates Explorer keyboard shortcuts across all modal overlays (`settings_open`, `guide_open`, `drawer_open`, `support_open`, release modal, and `explorer.modal`).
- **Frameless Resizable Window, Native Titlebar, Terminal Workspace & AI Support Prompt Modal (`shell/window.rs`, `desktop/{resize,titlebar,terminal,panels}.rs`, `desktop/modals/support.rs`)**: Window enables `.with_resizable(true)` at `[960, 720]` default / `[610, 480]` min, handles 8-direction `6px` perimeter resizing (`handle_frameless_resize`), and supports `Ctrl/Cmd + =/- /0/scroll` zoom (`0.7..=2.0`). `render_custom_titlebar` places `[Theme] [Sync] [Terminal] [Settings] [HelpBook]` left of `vertical_divider` and `Minimize`/`Maximize`/`Close` (`< 460px` wraps below). Clicking **Terminal** (`IconKind::Terminal`) switches the workspace to `render_terminal_view` featuring two tabs: **Terminal Log** (`TerminalTab::Console` dark console stream) and **App Logs** (`TerminalTab::AppLogs` structured cards with `LogSeverity`, `OD-*` badges, timestamps, targets, masked messages, and `lookup_diagnostic` hints), plus search, severity filter (`All`, `WarnPlus`, `ErrorOnly`), `Copy`, `Clear`, and `Back`. Clicking **HelpBook** (`IconKind::HelpBook`) opens `render_support_modal` with `build_support_prompt` (installed `v<CARGO_PKG_VERSION>`, exact-tag `llm.txt`, main `llm.txt`, `CHANGELOG.md`, repository, release URLs, platform prompt guidance, and strict non-invention guardrail), `Copy`, `Open llm.txt`, and `View App Logs` (which switches to `TerminalTab::AppLogs`). `render_overlays` consumes `Key::Escape` so only the topmost open overlay closes. `render_notice_toast` renders floating bottom-right status/error toasts (`Order::Foreground`) that auto-dismiss after 5 seconds.
- **Centered Bento Grid Overview (`desktop/bento.rs`, `desktop/panels.rs`)**: `Storage & Workspace` displays `This PC Active` badge + `total.detail_text` + guarded `quota_progress_bar` (when `total.has_exact_total`) + `Open Folder` + `Open Settings` + **Explore** (`UiAction::OpenExplorer("")`); `Sync Pulse` displays the global sync health badge alongside the Docs badge + `Cache` readout and 3 telemetry subcards.
- **Scrollable Settings Modal, UI Font Picker/Importer, Version Hyperlink, Open-With Rules & Encrypted Backup (`desktop/modals/{settings,mod,font_ui,open_rules_ui,open_rules_actions,release}.rs`, `desktop/font_actions.rs`, `runtime/release_check.rs`)**: Modal renders dimmed backdrop (`Order::Middle`) and card (`Order::Foreground`) at `768px` max width with header gray `v<CARGO_PKG_VERSION>` hyperlink (`render_version_changelog_link`) to `CHANGELOG.md` and underlined `the-long-ride` author hyperlink (`https://the-long-ride.github.io/`) in `render_about_footer`, `Show OpenDrive in This PC` (logo + cloud quota card under `This PC -> Devices and drives`), `Cache Explorer Folder Paths`, optional **Check for GitHub Releases**, **Bandwidth** & **Cache Limit** sliders, fixed-size **UI Font** dropdown (`CloseOnClickOutside`, pinned `"Search installed fonts..."` above a `180px` `ScrollArea`) + **Reset Font** + **Browse** + Google Fonts / public `https://` CDN URL (with redirect/link validation) / local path **Import** (with clear internet-download note, `spawn_font_import`, mapping invalid/non-public URL vs download failures to `OD-FONT-001` / `OD-FONT-002` and handling disconnected workers), **Open With Rules** (`OpenRuleDraft`, live search, validation, **Cancel**/**Save**, **Edit**/**Remove**), and **Encrypted Credential Backup (`.odcred`)**. `ControlCenterApp::on_exit` and `WindowForceQuit` share `shutdown_session()`.
- **Connected Accounts, Centered Connect/Re-auth Modal & Visual Collapsible Setup Guide (`desktop/ledger/{mod,row}.rs`, `desktop/drawer/{mod,sections}.rs`, `desktop/{auth_handlers,auth_reauth}.rs`, `desktop/modals/{guide,guide_content,guide_visuals}.rs`)**: Header displays `"N account(s)"` + `+ Connect`. Both Dashboard `+ Connect` and Explorer sidebar `+ New Account` open the centered `render_connect_modal` with fresh blank fields (no pre-populated saved OAuth Client ID/Secret). Pending rows route `Sign In`/`Copy Link` without canceling active sessions; Service Account (`credential_set_id.is_nil()`) re-auth never leaks saved OAuth secrets; `is_credential_rejection_error` / re-auth credential errors open `open_reauth_drawer` with prefilled inputs so users can update Client ID/Secret or JSON and retry. Setup Guide renders visual 4-step diagrams (`render_oauth_flow_diagram`, `render_service_account_flow_diagram`) inside collapsible sections (`option_a_open: true` expanded by default, `option_b_open: false`, `tips_open: false` collapsed by default). The Browser Sign-In guide covers Personal mode for the Google account that created the app and External mode for multiple accounts. Both use a Desktop app Client ID and Secret. The service-account guide distinguishes editing existing shared My Drive files from uploading new files to a Shared Drive.
- **Account Avatars, Logo & Integrated System Tray (`design/avatars.rs`, `design/logo.rs`, `shell/tray.rs`, `desktop/mod.rs`)**: `decode_avatar_color_image` scales cached avatars onto `72x72`; `logo.rs` shares the portal mark across bar/window/tray/Windows `opendrive.ico`; `DesktopTray` prepends a disabled read-only `TrayAction::Summary` item updated live via `sync_tray_summary`.
