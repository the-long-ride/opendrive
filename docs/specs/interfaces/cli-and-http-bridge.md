# CLI Commands, Synchronous Control Bridge, and Auth Runners

## Purpose and boundaries
Provides the `opendrive` binary CLI, the shared synchronous `Bridge` connecting `AppController` (`opendrive-core`), `SyncEngine` (`opendrive-sync`), `SecretStore` (`opendrive-auth`), `MediaStreamServer`, and `MountManager`, background desktop authentication runners (`auth_runner`), persistent directory/store initialization helpers (`ui.rs`), and the optional `tray` runner.

- **In scope**: Synchronous CLI argument dispatch (`"" | "ui"`, `--self-check`, `authorize`, `list-root`, `status`, `mount`, `--mount-watchdog`, `tray`, `explore`, `sync-down`, `sync-up`, `sync-clear`, `open-item`, `stream`, `rename`, `rm|delete`, `cp|copy`, `mv|move`, `help|--help|-h`) with Windows GUI subsystem suppression + `attach_parent_console_if_needed`; Windows PE icon resource embedding (`build.rs`); `AppLogHub` + `mask_sensitive_text` (`app_logs.rs`, `log_mask.rs`); system & Google Fonts discovery/validation/importer (`fonts.rs`, `font_import.rs`); localhost HTTP/1.1 range streaming (`MediaStreamServer` in `media_server.rs`); `Bridge` explorer/sync/file-op/batch/open-with/font operations (`explorer_ops.rs`, `explorer_file_ops.rs`, `explorer_batch.rs`, `explorer_open.rs`, `explorer_helpers.rs`); synchronous `Bridge` state snapshots (`bridge_types.rs`), secret store wiring, and mutations (`bridge.rs`, `bridge_vault.rs`); `MountBackend` (`backend.rs`, `live.rs`, `virtual_drive.rs`) & `MountManager` (`mount_manager/mod.rs`, `sync_ops.rs`); `AuthEndpoints`, `AuthSession`, `start_browser_oauth`, `start_service_account_auth` (`auth_runner/*`); and system tray loop (`shell/tray_loop.rs`).
- **Out of scope**: OAuth PKCE / Service Account JWT primitives (`opendrive-auth`), Drive HTTP transport (`opendrive-drive`), OS VFS adapters (`opendrive-fs-*`), `OD-*` catalog definitions (`opendrive-core/src/error_codes.rs`), and `eframe`/`egui` widget rendering (`design/*`, `desktop/*`).

## Observable behavior

### CLI Entrypoints, Windows Console Suppression & PE Icon (`build.rs`, `main.rs`, `runtime/cli.rs`, `cli_commands.rs`, `cli_self_check.rs`, `ui.rs`)
- **Default (`""` or `"ui"`)**: Release builds set `#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]` so double-clicking the GUI opens no console window; when invoked for CLI commands, `attach_parent_console_if_needed` attaches to the parent terminal. `build.rs` embeds multi-resolution `docs/assets/opendrive.ico` into `opendrive.exe` on `windows-msvc`. Runs `ui::run_desktop_ui(ui::load_controller())` synchronously without spawning any Tokio runtime threads.
- **`--self-check` (`cli_self_check.rs`)**: Starts an in-process mock Drive server and runs end-to-end checks for `SyncEngine`, `StreamCache`, `MediaStreamServer` (`206 Partial Content`), `OpenWithRule`, `explorer_open_item`, `explorer_sync_down`, `explorer_sync_up_and_clear`, `explorer_sync_up`, `explorer_{rename,copy,move,delete}_item`, and `compute_explorer_quota`.
- **Interactive Admin / Mount / Watchdog / Tray (`main.rs`, `runtime/cli.rs`)**: `tray` (`--features tray`), `authorize <client_id> <client_secret>`, `mount <access_token> [path]`, and hidden `--mount-watchdog <pid> <mount_root> [letter]` live in `main.rs`; `list-root <access_token>` (`list_root_with_base`), `status` (`status_cmd`), and `help|--help|-h` live in `runtime/cli.rs` (with `dispatch_bridge` for testable CLI routing).
- **Headless Explorer & Streaming (`runtime/cli.rs`, `cli_commands.rs`)**:
  - `explore <account> [remote_path]`: Lists children with size, `NodeState`, and UTC modified timestamp.
  - `sync-down <account> <remote_path>`: Downloads a file or recursive folder locally via `Bridge::explorer_sync_down`.
  - `sync-up <account> <local_path> [remote_parent]`: Uploads a local file or recursive directory via `Bridge::explorer_sync_up`.
  - `sync-clear <account> <remote_path>`: Uploads/verifies and clears local replicas via `Bridge::explorer_sync_up_and_clear`.
  - `open-item [--dry-run] <account> <remote_path>`: Resolves `OpenWithRule` / OS default target (and launches unless `--dry-run`, waiting for `Ctrl+C` in interactive streaming mode so the localhost `MediaStreamServer` stays live).
  - `stream [--probe] <account> <remote_path>`: Pre-warms head/tail chunks, starts `MediaStreamServer`, prints the localhost URL, optionally sends a `Range: bytes=0-65535` probe asserting `206 Partial Content`, and waits on `Ctrl+C` in `dispatch` mode so players can keep streaming.
  - `rename <account> <remote_path> <new_name>`, `rm|delete <account> <remote_path>`, `cp|copy <account> <remote_path> [dest_folder]`, and `mv|move <account> <remote_path> <dest_folder>` (`explorer_file_ops.rs`): Delete (Trash + local remove), rename, copy, and move Cloud or Local files/folders in lockstep via `Bridge::explorer_{delete,rename,copy,move}_item`.

### Localhost HTTP/1.1 Streaming Server & Explorer Operations (`media_server.rs`, `explorer_ops.rs`, `explorer_file_ops.rs`, `explorer_helpers.rs`, `explorer_open.rs`)
- `MediaStreamServer::start(engine, rt)` binds `127.0.0.1:0` with a random UUID session token and exposes `/stream/<token>/<node_id>/<encoded_name>`. Rejects invalid methods/tokens with `403 Forbidden`, missing/trashed/folder nodes with `404 Not Found`, and invalid ranges with `416 Range Not Satisfiable`. Supports `GET` and `HEAD` with `Accept-Ranges: bytes`, `Cache-Control: no-store`, `Content-Type` inference (`content_type_for`), `parse_http_range` (`bytes=start-end`, `bytes=start-`, `bytes=-suffix`), and `512 KiB` streaming chunks backed by `SyncEngine::read_cached_range(node_id, offset, want, 3)`.
- `Bridge::explorer_root_node`, `explorer_shared_with_me_node`, `explorer_list` (reconciling mounted Windows CFAPI placeholder entries), `explorer_local_entries`, `explorer_sync_down` (reconciling Windows CFAPI placeholder entries if mounted), `explorer_sync_up` (enforcing `!read_only`), `explorer_sync_up_node`, `explorer_sync_up_and_clear`, `explorer_{delete,rename,copy,move}_item`, `explorer_{sync_down,sync_up,sync_clear,delete,copy,move}_batch`, `explorer_stream_url`, `explorer_open_item`, `update_open_with_rules`, `remove_open_with_rule`, `update_explorer_folder_cache`, and `update_ui_font`.

### App Logging, Credential Masking & Font Importer (`app_logs.rs`, `log_mask.rs`, `fonts.rs`, `font_import.rs`, `font_url.rs`)
- `init_app_logging()` installs a `tracing_subscriber` registry with both a filtered stderr `fmt::layer` (`<= WARN` or `opendrive*` targets) and an `AppLogHub` capture layer retaining up to 1,000 `AppLogEntry` items. `record_event` infers structured `OD-*` codes from raw text via `opendrive_core::infer_diagnostic_code`, then masks PEM private-key blocks, `GOCSPX-*`, `ya29.*`, `1//*`, `Bearer ...`/`BEARER ...`, `*.apps.googleusercontent.com` client ID prefixes, and secret/token/password/`code=` values (preserving 3-digit HTTP status codes such as `code=403`) via `mask_sensitive_text` before storing.
- `fonts.rs`, `font_url.rs`, & `font_import.rs` parse SFNT/OpenType (`TTF`/`OTF`/`TTC`) headers + UTF-16/Mac `name` table family IDs (`validate_font_bytes`), discover system + `<data_dir>/fonts` fonts (`discover_system_fonts` skipping symlinks and preferring Regular faces), validate/copy local font files (`import_local_font_file`), download public `https://` font/CDN links or CSS `@font-face` endpoints (`validate_public_font_url` blocking HTTP, credentials, localhost/private/link-local/CGNAT IPs, `.local`/`.internal`/`.lan`, and `401`/`403` private URLs via `import_font_from_url`), and download Google Fonts CSS2 `.ttf`/`.otf` assets up to `20 MiB` (`import_google_font_family`, `spawn_font_import`).

### Synchronous Bridge, Secret Wiring & Mount Manager (`bridge*.rs`, `ui.rs`, `mount_manager/*`)
- `Bridge::new_with_secrets`, `with_data_dir`, `with_mount_manager`, `state_snapshot`, `add_account`, `account_action` (including `"move_up"` / `"move_down"` order persistence), `modify_settings`, `update_settings`, `update_virtual_drive`, `evict_cache`, `rename_account`, `export_encrypted_vault`, `import_encrypted_vault`, and `spawn_mount_sync` coordinate controller state, `SecretStore`, `SyncEngine`, and `MountManager`.
- `ui::build_bridge_in_dirs_with_secrets` and `build_persistent_bridge` configure `SyncEngine::set_stream_cache_dir(<data_dir>/stream_cache)` when `data_dir` is present, and `build_persistent_bridge` installs process console/close cleanup guards (`install_process_mount_guards`) and reconciles disabled `This PC` namespace state on startup.
- `MountBackend` (`backend.rs`, `live.rs`) supports `sync_this_pc_namespace` (primary Windows **This PC** OpenDrive logo + `ExplorerQuota` registration; `NullMountBackend` validates `!(enabled && root.is_file())` for headless tests), `reconcile_placeholder_entries`, `unregister_account`, `unregister_all_accounts`, `dehydrate_path`, `cleanup_legacy_subst`, and `set_virtual_drive_with_quota`; `token_refresh.rs` wires `AccountTokenRefresher` into `DriveClient`; `watchdog.rs` hosts `cleanup_os_mounts`, `cleanup_os_mounts_for_pid` (`mount-owner.pid` + `is_process_alive`), `install_process_mount_guards`, and `spawn_mount_watchdog`; `virtual_drive.rs` syncs `This PC` quota visibility and cleans up legacy `subst` drive letters while `MountManager::shutdown_all` tears down mounts cleanly on exit or `Drop`.
- `start_browser_oauth` and `start_service_account_auth` run in background worker threads (detecting unexpected disconnects via `AuthSession::try_recv`), awaiting `complete.rs` async avatar caching before finishing `finish_or_update_account` (preserving updated `nickname` and `read_only` while keeping `folder_name`) without nested `block_on`.

## Code map
- `crates/opendrive-app/build.rs` — Embeds multi-resolution `docs/assets/opendrive.ico` Win32 `.res` resource into `opendrive.exe` on `windows-msvc`.
- `crates/opendrive-app/src/lib.rs` — Exports `design`, `desktop`, `runtime`, and `shell` modules.
- `crates/opendrive-app/src/main.rs` — Synchronous binary entrypoint with Windows GUI subsystem flag + `attach_parent_console_if_needed`, dispatching UI, interactive `authorize`/`mount`, `--mount-watchdog`, or `runtime::cli` commands.
- `crates/opendrive-app/src/runtime/{app_logs,log_mask,fonts,font_import,font_url}.rs` — `AppLogHub`, `mask_sensitive_text`, SFNT font validation/discovery (`validate_font_bytes`, `discover_system_fonts`), public HTTPS CDN URL validation (`validate_public_font_url`), and Google Fonts / CDN / local `.ttf`/`.otf` import worker (`spawn_font_import`).
- `crates/opendrive-app/src/runtime/{cli,cli_commands,cli_self_check}.rs` — CLI parser (`dispatch`, `dispatch_bridge`, `status_cmd`, `list_root_with_base`), Explorer/stream subcommands (`cli_commands.rs`), and self-contained `--self-check`.
- `crates/opendrive-app/src/runtime/{media_server,explorer_batch,explorer_ops,explorer_file_ops,explorer_helpers,explorer_open}.rs` — `MediaStreamServer`, `BatchOutcome`, `ExplorerEntry` (with hierarchical `ExplorerSyncStatus`), `node_to_entry_for`, `ResolvedOpenTarget`, Explorer sync/file-op (`delete`/`rename`/`copy`/`move` + CLI `rm`/`rename`/`cp`/`mv` + batch helpers)/stream/open operations, `update_open_with_rules`, `remove_open_with_rule`, `update_ui_font`, and Windows tree dehydration.
- `crates/opendrive-app/src/runtime/{bridge,bridge_types,bridge_vault,ui,mod}.rs` — `Bridge`, `AppStateResponse`, vault export/import, and persistent runtime builders (`stream_cache` wiring).
- `crates/opendrive-app/src/runtime/mount_manager/{mod,backend,live,sync_ops,token_refresh,virtual_drive,watchdog}.rs` — `MountBackend`, `NullMountBackend`, `LiveMountBackend`, `AccountTokenRefresher`, watchdog/cleanup guards, multi-account mount lifecycle, and `This PC` `ExplorerQuota` sync.
- `crates/opendrive-app/src/runtime/auth_runner/{mod,complete,endpoints}.rs` — `AuthEndpoints` (`google_fonts_css_base`, pickers, launcher), `AuthSession`, and OAuth/Service Account completion.
- `crates/opendrive-app/src/shell/tray_loop.rs` — Optional (`tray` feature) system tray loop (calling `MountManager::shutdown_all` on `TrayAction::Quit`).
- `crates/opendrive-app/tests/{bridge_ui_tests,cli_and_explorer_cov_tests,diagnostics_and_logging_tests,font_cdn_tests,media_stream_and_cli_tests,mount_manager_tests,review_fixes_tests,runtime_cli_coverage_tests,runtime_cov_extra_tests,runtime_coverage_tests,runtime_explorer_cov_tests,runtime_vault_cov_tests,support/mod,token_refresh_and_scope_tests,ui_and_cli_cov_final_tests}.rs` — Integration tests for `Bridge`, `AppLogHub`/`mask_sensitive_text`, public HTTPS CDN font URLs, `MountManager`, `AccountTokenRefresher`, `This PC` quota sync, `MediaStreamServer`, `StreamCache`, vault backup flows, and `runtime::cli` subcommands.
